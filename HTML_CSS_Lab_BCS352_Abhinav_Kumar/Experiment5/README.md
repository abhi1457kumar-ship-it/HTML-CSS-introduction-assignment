## Aim

Link two pages with relative paths and display a picture with dimensions and descriptive alternative text.

## Tools required

A code editor and a web browser.

## Theory

The anchor element connects pages using its href value.  
Relative paths describe where a file is located from the current page, and two dots move up one folder.  
The img element displays a picture from a source.  
Width and height reserve image dimensions.  
Alternative text describes an image for readers and assistive technology.
