## Aim

Use px, percent and rem units and reuse colors and spacing through CSS custom properties.

## Tools required

A code editor and a web browser.

## Theory

CSS units express dimensions and text sizes.  
Pixels give fixed measurements, percentages relate to a containing size, and rem values relate to the root font size.  
Custom properties store reusable values, often in :root.  
The var() function applies them in rules.  
Reusable color and spacing values act as design tokens.
