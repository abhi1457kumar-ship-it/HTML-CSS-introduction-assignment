## Aim

## Tools required

A code editor and a web browser.

## Theory

CSS controls the appearance of HTML.  
Styles can be written inline on an element, inside a style block, or in a linked stylesheet.  
Element selectors target tags, class selectors target reusable groups and id selectors target a unique element.  
Properties such as color, font-style, text-decoration and font-size change text presentation.
