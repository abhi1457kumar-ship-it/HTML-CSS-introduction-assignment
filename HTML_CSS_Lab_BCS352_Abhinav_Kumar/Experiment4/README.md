## Aim

Group page parts with div elements, use id and data attributes, and repair malformed HTML.

## Tools required

A code editor and a web browser.

## Theory

A div groups related content into a block.  
Classes can be shared, while an id identifies one element on a page.  
CSS can select either attribute to style content.  
Custom data attributes store extra information on an element.  
Matching closing tags keep the document structure well formed.
