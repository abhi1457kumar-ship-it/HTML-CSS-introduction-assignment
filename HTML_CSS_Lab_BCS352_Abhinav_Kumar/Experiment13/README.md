## Aim

## Tools required

A code editor and a web browser.

## Theory

Flexbox arranges items along a row or column within a container.  
Display flex creates the container and its children become flex items.  
Justify-content aligns along the main axis, while align-items works across it.  
The gap property spaces items.  
Flex-wrap lets items continue on another line when space is limited.
