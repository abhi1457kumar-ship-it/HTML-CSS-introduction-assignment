## Aim

Use CSS Grid for equal columns, an auto-filling gallery and a named-area layout.

## Tools required

A code editor and a web browser.

## Theory

CSS Grid arranges content in rows and columns.  
Display grid establishes a grid container, and grid-template-columns defines its tracks.  
Fractional units divide available space, while gap separates items.  
Repeat and minmax can create a gallery that adapts to available width.  
Named areas give layout regions readable names.

## Tasks

### Task 1

**Aim:** Arrange six numbered boxes in three equal grid columns.

**Files:** `task1.html`, `task1.css`, `screenshot_task1.png`

Steps:

### Task 3

**Aim:** Lay out a header, sidebar, main panel and footer by name.

**Files:** `task3.html`, `task3.css`, `screenshot_task3.png`
