## Aim

Use media queries to adapt layouts and text and make an image scale responsively.

## Tools required

A code editor and a web browser.

## Theory

Responsive design adapts content to different screen sizes.  
The viewport meta tag gives mobile browsers the device's actual width.  
Mobile-first styles begin with a compact layout.  
A media query applies extra rules when its condition matches, such as a minimum width.  
Max-width and auto height let images scale without distortion, while rem units keep text proportional.

## Tasks

### Task 1

**Aim:** Stack cards on phones and place them side by side on wider screens.

**Files:** `task1.html`, `task1.css`, `screenshot_task1.png`

Steps:
1. Create two cards with headings and explanatory text.
2. Keep the base layout stacked for narrow screens.
3. Use a min-width 600px media query to create a flex row.

### Task 2

**Aim:** Scale an image to its containing width while preserving its ratio.

**Files:** `task2.html`, `task2.css`, `screenshot_task2.png`

Steps:
1. Add a heading and an image with descriptive alt text.
2. Set max-width to 100% and height to auto.
3. Link task2.css and resize the browser.

### Task 3

**Aim:** Change the heading size at a 600px viewport width.

**Files:** `task3.html`, `task3.css`, `screenshot_task3.png`

Steps:
1. Add the heading and paragraph.
2. Set body and base heading sizes in rem units.
3. Use a 600px media query to enlarge the heading.
