## Aim

Build tables with captions, headers, body rows, averages, footers and scope attributes.

## Tools required

A code editor and a web browser.

## Theory

Tables organize related data in rows and columns.  
Table, tr, th and td elements provide the structure.  
Caption names the table, while thead, tbody and tfoot group its parts.  
Scope identifies whether a heading describes a row or a column.  
These groups and headers improve navigation for assistive technology.
