## Aim

Create unordered, nested ordered and description lists for different types of related content.

## Tools required

A code editor and a web browser.

## Theory

HTML provides several list structures for related information.  
An unordered list displays bullets, and an ordered list numbers its items.  
Each item belongs in an li element.  
A list nested inside an item expresses subchoices.  
A description list pairs terms in dt with explanations in dd.
