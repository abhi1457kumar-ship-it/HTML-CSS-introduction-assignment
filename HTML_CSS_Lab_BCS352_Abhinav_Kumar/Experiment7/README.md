## Aim

Build an About Me page using semantic landmarks, in-page links and an email contact link.

## Tools required

A code editor and a web browser.

## Theory

Semantic elements describe the purpose of page regions.  
Header, nav, main, section and footer help people and assistive technology understand the structure.  
Fragment links beginning with # navigate to an element with the matching id.  
A mailto link opens an email application addressed to the linked contact.

## Tasks
