## Aim

Write HTML pages with document structure, titles, headings, paragraphs and basic text formatting.

## Tools required

A code editor and a web browser.

## Theory

HTML provides the structure of a web page.  
The doctype, html, head and body elements form a standard document.  
The head holds metadata and a title, while the body holds visible content.  
Heading elements express levels of importance, and paragraphs hold blocks of text.  
Strong, em and br add meaning and line breaks.
