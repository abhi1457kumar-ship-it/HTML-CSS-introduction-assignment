## Aim

Create labeled signup fields, radio choices, a course dropdown and browser-required inputs.

## Tools required

A code editor and a web browser.

## Theory

Forms collect information through controls such as text, email and password inputs.  
Labels connect readable descriptions to controls by matching for and id values.  
Radio buttons with the same name form a single-choice group.  
Select and option elements provide a dropdown.  
Required and placeholder attributes guide and validate entry.
