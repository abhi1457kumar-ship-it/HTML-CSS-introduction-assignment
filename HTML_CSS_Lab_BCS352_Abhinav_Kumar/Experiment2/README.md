## Aim

Create a local bare remote, push the lab commits to it, and clone it into a second working folder.

## Tools required

Git and a terminal.

## Theory

A remote repository is a second copy used to share or back up commits.  
A bare repository stores Git history without a working folder.  
A remote name such as origin saves a repository address.  
The push command sends branch commits to that address.  
The clone command copies a repository and its history into a new folder.
