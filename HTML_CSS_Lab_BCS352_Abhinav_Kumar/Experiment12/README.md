## Aim

Compare box-sizing behavior, style a card and make an overflowing box scroll.

## Tools required

A code editor and a web browser.

## Theory

The box model consists of content, padding, border and margin.  
With content-box, padding and border add to the declared width.  
With border-box, they fit inside it.  
Cards combine spacing, color, borders and rounded corners to group content.  
Overflow auto provides scrolling when content exceeds a fixed region.

## Tasks

### Task 1

**Aim:** Compare content-box and border-box with matching dimensions.

**Files:** `task1.html`, `task1.css`, `screenshot_task1.png`

Steps:
1. Create content-box and border-box examples.

### Task 3

**Aim:** Make a fixed-height box scroll through five lines.

**Files:** `task3.html`, `task3.css`, `screenshot_task3.png`
