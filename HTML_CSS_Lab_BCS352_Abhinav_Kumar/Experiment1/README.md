## Aim

Start a Git repository for the lab work, configure its local author identity, and save page changes in commits.

## Tools required

Git and a terminal.

## Theory

Git records a project's changes so earlier work can be reviewed and restored.  
A repository is a folder that Git tracks.  
The init command begins tracking; local configuration stores the author identity for that repository.  
The status and add commands show and stage changes.  
A commit saves a snapshot, while log shows saved history.
